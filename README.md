# DevOps Academy – Track 1

## Introduzione

Benvenuti in questa repository, realizzata come parte del mio percorso formativo presso la **DevOps Academy - Sourcesense**.

Questa repository raccoglie il lavoro svolto durante l'intera **Track 1/2**, includendo esercitazioni pratiche, configurazioni, script e progetti sviluppati seguendo le attività e le indicazioni fornite nel corso della formazione.

L'obiettivo è documentare il percorso di apprendimento, consolidare le competenze acquisite e mantenere una raccolta organizzata degli strumenti e delle tecnologie esplorate durante la Track.

## Contenuto della repository

All'interno della repository sono presenti materiali relativi a diversi argomenti del mondo DevOps, tra cui:

- Linux e shell scripting
- Git e GitHub
- Containerizzazione con Docker e Podman
- Jenkins e pipeline CI/CD
- Kubernetes
- Infrastructure as Code
- Configurazioni, esempi pratici ed esercitazioni

Ogni cartella contiene un proprio `README.md` con la descrizione del contenuto e una spiegazione delle configurazioni o degli script presenti.

## Obiettivo

Questa repository ha lo scopo di raccogliere e documentare il percorso svolto durante la DevOps Academy, rappresentando un riferimento sia per il ripasso degli argomenti affrontati sia come portfolio delle competenze sviluppate durante la formazione.
